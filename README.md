# Enshrouded Mods

Choose a mod below for its download, supported game and ShroudForge versions,
and mod-specific setup. The [shared installation guide](docs/install-mods.md)
explains how to install ShroudForge itself, add any ShroudForge mod, fix or
bypass WebView2 window problems, and update mods without replacing personal
settings. Download the named ZIP assets from
[Releases](https://github.com/Tellik/enshrouded-mods/releases), not GitHub's
generated source archives.
